📈 Marketing Campaign Attribution Project

Overview

This project builds a marketing attribution system using Fivetran, BigQuery, dbt, Airflow, and Tableau. It integrates ad platform data, applies attribution models, and visualizes ROI across channels.

Architecture

  • Ingestion: Fivetran pulls Google Ads, Facebook Ads, and CRM data into BigQuery.
  • Transformation: dbt applies first-touch, last-touch, and linear attribution models.
  • Orchestration: Airflow schedules dbt runs and keeps data fresh.
  • Visualization: Tableau dashboard compares CAC, LTV, and ROI across channels.

Pipeline Flow

  1. Ad platform + CRM data → BigQuery via Fivetran.
  2. dbt models apply attribution transformations.
  3. Airflow orchestrates the pipeline daily.
  4. Tableau dashboard visualizes ROI, CAC, LTV.

Example dbt Model

  -- models/marts/fact_attribution.sql
  SELECT
    c.customer_id,
    a.channel,
    COUNT(*) AS touches,
    SUM(a.spend) AS total_spend
  FROM {{ ref('stg_ads') }} a
  JOIN {{ ref('stg_customers') }} c ON a.customer_id = c.customer_id
  GROUP BY c.customer_id, a.channel;

Airflow DAG Example

  from airflow import DAG
  from airflow.operators.bash import BashOperator
  from datetime import datetime

  with DAG("marketing_attribution", start_date=datetime(2023,1,1), schedule_interval="@daily", catchup=False) as dag:
      run_dbt = BashOperator(
          task_id="run_dbt",
          bash_command="cd /usr/local/airflow/dbt && dbt run"
      )
