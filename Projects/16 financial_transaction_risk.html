Case Study: Financial Transactions Risk Monitoring

Overview

This project focuses on building a real-time risk monitoring pipeline for financial transactions. The goal was to detect suspicious activities, reduce fraud exposure, and improve compliance monitoring.

Objectives

  • Ingest transaction logs in near real-time.
  • Build anomaly detection logic for suspicious transactions.
  • Model transactions and customer risk profiles.
  • Trigger alerts for compliance and risk teams via Slack.

Architecture

The high-level pipeline architecture is shown below:

  • Source: Transaction logs streamed via Kafka (or batch CSVs for demo).
  • Storage: S3 bucket for raw logs.
  • Warehouse: Snowflake external stage integration.
  • Transformations: dbt models for staging, fact_transactions, and risk scores.
  • Orchestration: Airflow DAG with Slack alerts.
  • Monitoring: Anomaly detection queries flagged suspicious activities.

Example dbt Model

  -- models/marts/fct_transactions_risk.sql
  SELECT
    t.transaction_id,
    t.customer_id,
    t.amount,
    t.transaction_date,
    c.risk_category,
    CASE
      WHEN t.amount > 10000 THEN 'HIGH_RISK'
      WHEN t.amount > 5000 AND c.risk_category = 'Medium' THEN 'MEDIUM_RISK'
      ELSE 'LOW_RISK'
    END AS risk_score
  FROM {{ ref('stg_transactions') }} t
  JOIN {{ ref('stg_customers') }} c 
    ON t.customer_id = c.customer_id;

Airflow DAG with Slack Integration

  from airflow import DAG
  from airflow.operators.bash import BashOperator
  from airflow.providers.slack.operators.slack_webhook import SlackWebhookOperator
  from datetime import datetime

  with DAG("risk_monitoring_pipeline",
           start_date=datetime(2023,1,1),
           schedule_interval="@hourly",
           catchup=False) as dag:

      run_dbt = BashOperator(
          task_id="run_dbt",
          bash_command="cd /usr/local/airflow/dbt && dbt run"
      )

      notify_slack = SlackWebhookOperator(
          task_id="notify_slack",
          http_conn_id="slack_conn",
          message="⚠️ Risk monitoring pipeline detected anomalies!",
          channel="#risk-alerts"
      )

      run_dbt >> notify_slack

Key Outcomes

  • Developed risk-scoring models for transactions.
  • Automated fraud detection alerts via Slack.
  • Improved compliance reporting with near real-time monitoring.

This project highlights risk analytics, real-time monitoring, and pipeline observability, integrating cloud storage, Snowflake, dbt, and Airflow.
