📊 E-Commerce Sales Analytics Project

Overview

This project demonstrates how to build a modern analytics engineering pipeline using Fivetran, Snowflake, dbt, Airflow, and Tableau. It ingests raw e-commerce data, transforms it into analytics-ready tables, and visualizes insights for business users.

Architecture

  • Ingestion: Fivetran syncs Shopify data (orders, customers, products) into Snowflake.
  • Transformation: dbt creates staging and marts (star schema with fact_sales, dim_customer, dim_product).
  • Orchestration: Airflow DAG schedules dbt runs and ensures freshness.
  • Visualization: Tableau dashboard with KPIs like Revenue, LTV, Churn Rate.

Pipeline Flow

  1. Raw data → Snowflake via Fivetran.
  2. dbt models transform raw data into clean tables.
  3. Airflow triggers transformations daily.
  4. Tableau dashboard consumes the analytics tables.

Example dbt Model

  -- models/marts/fact_sales.sql
  SELECT 
    o.order_id,
    o.order_date,
    c.customer_id,
    p.product_id,
    o.total_amount
  FROM {{ ref('stg_orders') }} o
  JOIN {{ ref('stg_customers') }} c ON o.customer_id = c.customer_id
  JOIN {{ ref('stg_products') }} p ON o.product_id = p.product_id;

Airflow DAG Example

  from airflow import DAG
  from airflow.operators.bash import BashOperator
  from datetime import datetime

  with DAG("dbt_pipeline", start_date=datetime(2023,1,1), schedule_interval="@daily", catchup=False) as dag:
      run_dbt = BashOperator(
          task_id="run_dbt",
          bash_command="cd /usr/local/airflow/dbt && dbt run"
      )
